# 2-minute video script

Target length **1:58**. About 300 words of voice-over at a steady pace (150 words a minute). Record the screen at 1440×900 or larger in dark mode, speed "Normal". Words to say are in quotes; what to show is in italics.

Record against the team's live server address so the "pick two real objects" shot works; the public site works for everything else.

## If you run long

Cut in this order: the last sentence of the 0:22 beat ("So we added…"), then the ledger sentence at 1:20.

## Recording tips

- Load each page once before recording so fonts, data and the globe are cached; press Escape if the tour opens.
- For the 0:30 beat, select the scenario and press Run before you start speaking; the dialog opens at the first step, so pause on it while you say the 0:50 lines.
- For the 1:20 beat, have the two names ready to paste; the simulator answers in about a second.
- Keep the "illustrative" labels on screen; they are already there.
- Say "safety layer" and "priority check"; the on-screen words match.
